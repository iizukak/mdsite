## 5 ：名無しさん：2026/10/30(木) 12:15:08

> インストール方法を教えてください。

uv と GNU Make が入っていれば、これだけでいけます。

```
$ git clone git@github.com:iizukak/mdsite.git
$ cd mdsite
$ make install
```

あとは `mdsite.yaml` を置いたディレクトリで `mdsite` を実行するだけです。
